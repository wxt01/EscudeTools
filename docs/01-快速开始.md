# 快速开始

从零到「游戏里看到中文」，五步。假设你已有一个日文原版游戏目录（自备）。

---

## 0. 环境

```bat
python --version              :: 3.10 以上
pip install pillow numpy fonttools
```

- `pillow` 画字库页
- `numpy` 界面图像素处理
- `fonttools` 码表生成（`gen_font.py` 用它检查字形覆盖）
- `tkinter` 是 Python 自带的，图形工具需要它（精简版 Python 可能没有）

还需要一个能解 `ESC-ARC2` 的命令行工具，见 `vendor/README.md`。

---

## 1. 建项目目录

```bat
mkdir myproject
copy project.example.json myproject\project.json
```

编辑 `myproject\project.json`，至少填两项：

```json
{
  "game_dir": "D:\\Games\\YourGame",
  "engine_tool": "D:\\Tools\\EscudeTools\\EscudeTools.exe"
}
```

> 目录名随意，但建议保持 `0_backup`…`6_release` 这套默认值，脚本之间靠它对齐。

---

## 2. 一键准备

```bat
python scripts\prepare.py --project myproject
```

也可以不给 `--project`，直接在项目目录里运行（脚本会向上找 `project.json`）。

**它会做七件事**，每步都有输出：

| 步骤 | 产出 | 检查点 |
|---|---|---|
| 备份 | `0_backup\*.bin` | 三个包都在，体积正常 |
| 解包 | `1_unpack\output\{script,data,gfx}` | `script\` 里有大量 `.bin`/`.001` |
| 解脚本 | `1_unpack\output\script.db` | 几十 MB，能打开 |
| 解数据库 | `1_unpack\output\db_*.db` | 有 `db_scripts.db` 说明人名可翻 |
| 提取 | `2_json_jp\*.json` | 每个脚本一个文件 |
| 干净底版 | `4_pristine\` | 之后所有构建都从这里取 |
| 推断页号 | 写入 `project.json` 的 `font.max_page` | 打印「原版正文用到的最大页号」 |

最后一行会打印字数规模，先看一眼：

```
导出 60 个脚本，共 10992 条
```

---

## 3. 配置翻译后端

```bat
copy config.example.json scripts\config.json
```

填 `api_key`、`endpoint`、`model`。其它参数默认值已经调过：

- `reasoning_effort: "none"` —— 关掉思考模式
- `batch_size: 20` / `context_lines: 6` / `concurrency: 6`
- `max_lines: 12000` —— 防误触发全量的保险丝

再准备术语表 `scripts\glossary.tsv`（格式见 `glossary.example.tsv`）。
**这一步越认真，成品一致性越好**：人名、地名、组织名、专有名词全写进去，
日文和中文写法相同的也要写（否则模型会自由变体）。

---

## 4. 翻译

```bat
python scripts\hx.py translate myproject\2_json_jp myproject\3_json_cn
```

或双击 `bat\run_translate.bat` 并把项目文件夹拖上去。

- 支持断点续跑：已译的行不会重译，中断后重跑即可
- 失败会二分重试，最小到单条
- 每批写盘一次，随时可以看进度

跑完做质检：

```bat
python scripts\hx.py check myproject\3_json_cn
```

会报：空译、残留假名、长度溢出、控制标记丢失。

清理一遍（去注音、规范拟声、清占位符残留）：

```bat
python scripts\normalize_cn.py --project myproject
```

---

## 5. 构建

```bat
python scripts\build.py --project myproject
```

或双击 `bat\build.bat` 选 1。

产出 `myproject\6_release\`：

```
script.bin   gfx.bin   data.bin   使用说明.txt
```

把三个 `.bin` 拖进游戏目录覆盖，启动即中文。

**改译文后**不要跑全量（字库没变，重画是浪费时间）：

```bat
python scripts\build.py --project myproject --no-gfx
```

约 1 分钟出包。

---

## 6. 第一次跑建议按这个顺序验收

不要一上来就全量翻 3 万行。按这个顺序，每一步都能在游戏里看到结果：

1. **先验证显示层**：只翻开头 20 行（手写几句测试中文也行）→ 构建 → 进游戏看有没有中文
   - 这一步不过，后面全白做。80% 的问题（缺字、错位、空白）在这一步就能暴露
2. **再验证人名与界面**：填 `names_zh.json` 与 `ui_zh.json`（各十几条即可）→ 构建 → 看名字栏与设置界面
3. **然后全量翻译**：确认前两步没问题再放开 `max_lines`
4. **最后做界面图**：`ui_labels.json` / `ui_misc.json`，详见 `05-界面图汉化.md`

## 常见起步问题

| 现象 | 原因 |
|---|---|
| `缺少 game_dir` | `project.json` 没填，或路径用了单反斜杠转义错误（要写 `\\`） |
| `解包结果里没有 output/script` | `bins` 里没包含脚本包，或那个包不是 `ESC-ARC2` |
| 没有 `script.db` | 引擎工具的 `-v` 用法不同，先跑一次看它打印的帮助 |
| `没有现成码表` | `--no-gfx` 之前必须先成功跑过一次全量 |
| 进游戏还是日文 | 覆盖到了错误的目录（常见于有多个副本），或游戏在读别的包 |

更多见 `04-踩坑与FAQ.md`。
